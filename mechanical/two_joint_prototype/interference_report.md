# Inventor干渉・拘束検証

最終保存IPTの体積と全アセンブリ参照体積が一致した。旧版混入を検出するチェックを含む。

構成部品 32個、拘束 91個。固定Base、肩/肘は同軸mate＋軸方向flush、その他は3平面flushによる剛体接続。

ディスクからのcold reloadを実施、32 IDWも再読込みで参照欠落なし。

3平面flushによる剛体29組、固定1個、軸mate/flush2組の拘束構造では独立自由度2。Inventorで肩のみ・肘のみの角度変更が成立することを検証した。GetDegreesOfFreedomの数値取得はCOM出力型変換に失敗したためTBD。数値APIが成功したとは報告しない。

| 姿勢 | 肩/肘 deg | Update | solid干渉数 |
|---|---|---|---|
| initial | [0, 0] | True | 0 |
| maximum_flex | [75, 120] | True | 0 |
| extension | [0, 0] | True | 0 |
| middle | [35, 60] | True | 0 |
| lift | [60, 30] | True | 0 |
| shoulder_only | [30, 0] | True | 0 |
| elbow_only | [0, 60] | True | 0 |

全姿勢で91本の本拘束＋一時角度拘束の状態を記録。一時拘束は試験後に削除。保存・再読込み後、参照欠落なし。

この検査は7離散姿勢のCAD solid検査であり、連続全域、ケーブル、コネクタ、製造誤差、実ホーン形状、ねじ、弾性変形を含まない。公差を含む実機干渉検証はTBD。ストッパとばねは個別設計で、実動作検証に含めていない。
